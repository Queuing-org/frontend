# Change Summary

## Commits

1. `feat(ui): 친구 프로필과 방 상태 안내 정비`
2. `feat(settings): 회원 탈퇴 확인 흐름 개편`
3. `fix(room): 방 수정 액션과 참여 제한 정렬`
4. `docs(delivery): UI 후속 변경 검증 기록` (this run)

## Changed Behavior

- 친구 프로필의 불필요한 문구와 1줄 제한을 제거하고 긴 텍스트 표시를 보완했다.
- 방 프로필을 위쪽으로 확장해 음악력 아래 여백을 확보하고 중앙 방 컨테이너의 기존 제목 위 여백을 복구했다.
- 데스크톱 방 나가기 위치와 방장 승계 안내를 정비했다.
- 회원 탈퇴를 선택 필수 사유와 2초 지연 확인의 2단계 다이얼로그로 전환했다.
- 방 수정의 삭제 액션 문구/위치와 설정 control 정렬을 정비했다.
- 방 수정 기본 폭을 816px로 확장했다.
- 신청 버튼, 비로그인 상태, 신청 모달의 표기를 `노래신청`으로 통일했다.
