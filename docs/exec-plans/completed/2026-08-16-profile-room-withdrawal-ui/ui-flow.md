# UI Flow

## 친구 프로필과 방

- 친구 프로필은 activity label을 숨기고 닉네임과 소개에 2줄 clamp를 적용한다.
- 방 프로필은 하단 위치를 유지한 채 기본 높이를 431px로 늘리고 top을 60px로 올린다. compact는 같은 80% 비율을 적용한다.
- 방 프로필의 `현재 큐잉 중`은 본인/타인 공통 타이틀로 유지하고, 본인 곡 상태는 관리·팔로우 대체 영역에 표시한다.
- 데스크톱 나가기는 중앙 컨테이너 밖 viewport 좌상단에 두고 모바일 헤더 액션은 유지한다.
- 나가기 위치와 무관하게 중앙 컨테이너의 기존 제목 위 여백 60px, compact 48px을 유지한다.
- 방장 승계 모달은 같은 방에서 방장 여부가 `false -> true`가 된 경우에만 열린다.
- 최초 관찰값이 이미 방장이면 모달을 열지 않으며, 확인/Escape/배경 클릭으로 닫는다.

## 회원 탈퇴

- `WithdrawalDialog`가 단계, 선택 사유, 2초 타이머를 소유한다.
- `AccountSettingsTab`은 다이얼로그 열림, mutation, 성공 후 로그아웃 처리를 소유한다.
- 첫 단계는 복수 선택이며 선택이 없으면 진행 버튼이 비활성화된다.
- 두 번째 단계 진입 시 타이머를 시작하고 2초 뒤 최종 버튼을 활성화한다.
- 최종 버튼 비활성 텍스트는 `#d9d9d9`를 사용하고 감사 문구는 제공된 화면 문구를 따른다.
- 취소/Escape/배경 클릭은 다이얼로그를 unmount해 선택과 타이머를 초기화하고 mutation 오류도 reset한다.
- pending 중에는 취소와 최종 버튼을 비활성화하고 Escape/배경 닫기를 무시한다.
- 실패 시 두 번째 단계와 활성화 상태를 유지해 즉시 재시도할 수 있다.

## 방 수정

- 방 삭제는 header에서 제거하고 footer의 편집 완료 바로 위에 둔다.
- 방 수정 기본 폭은 816px로 확장하고 compact 폭은 652.8px을 유지한다.
- 두 footer 버튼은 동일한 너비, 높이, 타이포를 공유하고 삭제만 빨간색을 사용한다.
- 설정 바깥 grid는 데스크톱/compact에서 `4fr 1fr`을 사용한다.
- 곡당 제한과 참여 제한은 첫 번째 열 안에서 같은 label/control grid를 공유한다.
- 최대 인원은 두 번째 열에 두고 모바일에서는 전체 설정을 단일 열로 전환한다.
