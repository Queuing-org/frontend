# UI 흐름

## 이용 시간

1. 설정 프로필과 방 내부 프로필이 프로필 응답을 받는다.
2. 초 값을 시간·분 문자열로 변환한다.
3. 값이 없거나 유효하지 않으면 `-`를 유지한다.

## 태그 필터

1. `ALL` 상태에서는 태그 조건 없이 방 목록을 조회한다.
2. 태그를 누르면 `ALL`을 제거하고 선택 태그를 쿼리에 반영한다.
3. 선택 태그를 다시 누르면 해제한다.
4. 마지막 태그가 해제되면 `ALL`로 복귀한다.
5. 3개 선택 후에는 선택되지 않은 태그를 비활성화하고 이유를 툴팁으로 제공한다.
6. `ALL`을 누르면 모든 태그 선택을 해제한다.
