# UI Flow

## 채팅 타임스탬프

1. 채팅 문자열에서 유효한 `m:ss` 또는 `h:mm:ss`를 찾는다.
2. 현재 곡 길이보다 짧은 타임스탬프만 파란색 버튼으로 표시한다.
3. 클릭하면 현재 사용자 플레이어만 이동하고 서버에는 명령을 보내지 않는다.
4. 같은 곡의 이후 `PLAYBACK_SYNC`에서는 상태만 따르고 시간 보정은 건너뛴다.
5. 곡이 바뀌면 로컬 override를 제거하고 서버 시간 동기화에 복귀한다.

## 404

- 안내 본문과 별개로 좌상단에 공용 `MainLogo`, `RoomSearchButton`을 유지한다.

## 최애곡

- 라벨과 placeholder를 `최애곡`으로 통일한다.
- 입력값은 줄바꿈을 공백으로 바꾸고 최대 20자로 자른다.
- 입력 우측 내부에 흐린 회색 `{length}/20` 카운터를 표시한다.
