# 프로필 이용 시간·방 태그 필터·서버 주소 전환

## 상태

- 단계: local-verified
- 브랜치: `dev`
- 전달 대상: 기존 Draft PR #36

## 범위

- 내 프로필과 방 내부 신청자 프로필에 `listeningDurationSeconds`를 사람이 읽을 수 있는 이용 시간으로 표시한다.
- 홈과 검색의 원형 장르 필터를 최대 3개 다중 선택으로 활성화하고 `/api/v1/rooms`의 쉼표 구분 `tags` 요청에 연결한다.
- API, 웹소켓, 로컬 프론트 개발 주소를 `queuing.cc` 도메인으로 전환한다.

## 수용 조건

- 이용 시간이 누락되면 `-`, 값이 있으면 시간·분 단위로 두 프로필 화면에 표시된다.
- 장르 태그는 중복 없이 최대 3개 선택되며, 모든 태그 조건이 홈과 검색의 첫 페이지와 다음 페이지 요청에 유지된다.
- `ALL` 선택은 태그 조건을 제거한다.
- 런타임 설정과 개발 문서에 활성 `queuing.patulus.com` 주소가 남지 않는다.
- `npm run test`, `npm run lint`, `npm run build`와 fresh read-only QA를 통과한다.

## 결정

- 이용 시간은 화면 간 표현 차이를 막기 위해 사용자 프로필 도메인의 순수 포매터를 공유한다.
- 태그는 의미상 순서가 없으므로 쿼리 키와 요청을 안정화하기 위해 정규화·중복 제거·정렬한다.
- 기존 사용자 로컬 변경인 `FollowModal.module.css`의 검색 입력 폭/여백은 이 작업에서 수정하거나 커밋하지 않는다.
