# 친구 상세·설정·방 생성 태그 UI 후속 개선

## 상태

- ready
- 기준 브랜치: `dev`
- 전달 범위: 로컬 커밋까지만. push 및 PR 갱신/생성 제외

## 범위

- FRIEND 목록의 친구 상세를 방 내부 프로필과 같은 플로팅 패널 외형과 드래그 동작으로 통일한다.
- 친구 상세의 PROFILE 문구와 닫기 버튼을 제거하고 같은 카드를 다시 누르면 닫히게 한다.
- 탐색 모달이 열린 동안 FILTER 컨트롤을 숨기고 좌우 이동 버튼은 보이되 비활성화한다.
- 프로필 설정에서 한 줄 메시지 행을 세로 중앙 기준에 맞추고 피드백과 완료 버튼을 같은 행에 둔다.
- 생성 장르 단계에서 태그를 하나 이상 선택하도록 검증하고 FREE 태그를 첫 번째로 정렬한다.

## 경계와 결정

- 방 기능에서 중립적인 플로팅 패널 외형은 `src/shared/ui`로 이동해 방과 친구 기능이 함께 사용한다.
- 친구 상세 선택 상태는 `FollowModal`이 계속 소유하며 동일 slug 선택만 토글 닫기로 처리한다.
- 탐색 잠금은 방 이동/입장만 막고 MENU는 유지한다. FILTER는 열린 상태까지 정리한다.
- 태그 필수 검증은 다음 단계 이동과 최종 생성 직전에 모두 적용해 우회 생성을 막는다.
- API payload 및 공용 API 타입은 변경하지 않는다.

## 수용 기준

- 친구 상세가 300×380, compact 240×304 플로팅 프로필 패널 외형을 사용하고 드래그 핸들로 이동한다.
- 친구 상세에 보이는 PROFILE 제목과 X 버튼이 없고 같은 프로필 카드를 다시 누르면 닫힌다.
- 탐색 잠금 중 좌우 화살표는 disabled 상태로 남고 FILTER 버튼/패널은 없다.
- 설정의 한 줄 메시지 행이 세 입력 행의 세로 중앙이며 피드백과 완료 버튼이 같은 footer 행에 있다.
- 태그 0개로 다음을 누르면 `태그는 1개 이상 골라주세요`가 표시되고 장르 단계에 머문다.
- FREE 태그가 API 응답 순서와 무관하게 첫 번째로 표시된다.
