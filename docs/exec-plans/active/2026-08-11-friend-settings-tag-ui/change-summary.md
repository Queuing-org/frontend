# Change Summary

- 방 전용이던 플로팅 패널 외형과 드래그 핸들을 shared primitive로 이동해 방 프로필과 친구 상세가 같은 셸을 사용한다.
- 친구 상세의 PROFILE 제목과 X 버튼을 제거하고 Escape 및 동일 카드 재클릭으로 닫도록 바꿨다.
- 탐색 모달 중 좌우 화살표를 보이는 disabled 상태로 유지하고 FILTER 버튼과 열린 필터 상태를 정리한다.
- 설정의 세 입력 행만 세로 중앙 계산에 남겨 한 줄 메시지를 중앙에 두고, 피드백과 완료 버튼을 같은 footer 행으로 합쳤다.
- 방 생성 장르 단계에서 태그 1개 이상을 필수로 검증하고 FREE 태그를 응답 순서와 무관하게 첫 번째로 표시한다.
- 프로필 설정 form 전체를 normal 10px·compact 8px 위로 이동해 사용자 이름부터 완료 버튼까지 함께 상향했다.
- 후속 조정에서 form 상향값을 normal 15px·compact 12px로 늘리고 프로필 카드/피드백 스크롤을 차단했다. 모바일은 전체 높이 모달과 낮은 세로 점유 레이아웃으로 재배치해 스크롤 없이 완료 버튼까지 접근 가능하게 했다.
- API client, payload 및 공용 API 타입은 변경하지 않았다.
