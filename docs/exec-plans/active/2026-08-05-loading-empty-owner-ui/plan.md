# 로딩·빈 상태·선택 방 방장 UI 정리

## 목표

- 화면에 직접 노출되는 하드코딩 로딩 문구를 공통 스피너로 교체한다.
- 팔로워·팔로잉·차단 목록의 빈 상태를 같은 중앙 정렬 규칙으로 통일한다.
- 홈과 검색의 방 없음 상태를 제품 문구와 방 만들기 액션으로 교체한다.
- 홈 및 검색에서 선택된 방 썸네일에만 방장 정보를 같은 스타일로 표시한다.

## 작업 순서

1. 공통 로딩 스피너와 목록 상태 UI를 추가하고 노출형 로딩 문구를 교체한다.
2. 팔로우 관련 목록의 빈 상태 레이아웃을 통일한다.
3. 홈·검색의 빈 상태와 방 만들기 동작을 구현한다.
4. 선택 방 메타데이터를 사용해 홈·검색 썸네일 방장 바를 구현한다.
5. 관련 테스트, lint, build, 브라우저 QA를 수행한다.
6. 방 썸네일이 사용하는 YouTube 호환 도메인을 Next Image 허용 목록에 반영한다.

## 계약과 제약

- 서버 상태는 기존 TanStack Query 훅을 재사용한다.
- 방장 정보는 방 목록 응답에 임의 필드를 추가하지 않고 `useRoomMetaQuery` 결과를 사용한다.
- 선택되지 않은 방에는 방장 바를 렌더링하지 않는다.
- 브랜치는 `dev`, 전달 대상은 Draft PR #34이다.
