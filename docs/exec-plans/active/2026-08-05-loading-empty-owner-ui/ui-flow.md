# UI Flow

## 로딩 상태

- 화면에 직접 노출되던 `로딩중`, `불러오는 중`, `확인 중` 등의 진행 문구는 `LoadingSpinner`로 통일한다.
- 스피너는 진행 대상에 맞는 접근성 이름을 유지한다.
- 완료·오류·빈 상태처럼 사용자가 의미를 읽어야 하는 문구는 텍스트로 유지한다.

## 빈 상태

- 팔로워·팔로잉·차단 목록은 `FollowListState`를 공유하고 탭 패널 중앙에 배치한다.
- 홈의 방 없음 상태는 `현재 생성된 방이 없어요.`와 `방 만들기` 액션을 제공한다.
- 검색의 방 없음 상태는 검색어를 포함한 설명과 `방 만들러 가기` 액션을 제공한다.

## 선택 방 방장 표시

- 방 메타데이터의 공개 `owner` 필드만 사용한다.
- 홈 스테이지와 검색 미리보기 모두 선택된 방에만 `SelectedRoomOwnerBar`를 렌더링한다.
- 바는 높이 56px, `rgba(245, 245, 247, 0.8)`, 32px 아바타, 16px bold `#3c3c3c`를 사용한다.
