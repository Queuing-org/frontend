# Request Summary

- 팔로워와 팔로잉 카드에서 아바타 우측 하단에 온라인 초록 점, 오프라인 빨간 점을 표시한다.
- 공개 방 참여 중이면 `{방 제목} 참여 중`, 방이 없으면 온라인/오프라인 문구를 표시한다.
- 상태 문구는 기능이 없고 우측 화살표만 방으로 이동한다. 팔로잉의 언팔로우 기능은 제거한다.
- 음악력은 선택·재클릭 취소 없이 UP/DOWN 클릭 한 번으로 끝낸다. 같은 사용자는 1시간에 한 번 평가할 수 있다는 안내를 제공한다.
- 설정의 최애 곡을 제거하고 `칭호 없음`으로 대표 칭호를 해제한다.
- queue 모달에서 지난 곡 기능을 제거하고 전체 트랙에도 현재 재생 곡을 표시한다.
- 긴 신청 사연은 영역을 넘을 때 잘리지 않고 가로로 순환해 전체 문장을 보여준다.
- 칭호 획득 모달 디자인을 개선하고 폭죽 효과를 추가한다.
- 방 내부 프로필에서 최애곡을 한 줄 소개로 바꾸고 음악력 1시간 안내 문구를 제거한다.
- 차단 탭에서 차단 사용자 목록을 조회하고 같은 카드 스타일에서 차단 해제한다.
- 팔로잉/팔로워 카드를 누르면 관계 버튼과 차단 버튼을 표시한다.
- 재생목록과 현재 재생 신청자 카드의 긴 곡 제목도 영역을 넘을 때 가로로 순환한다.
- 현재 재생 곡 썸네일의 `PLAY` 문구를 애니메이션 equalizer로 바꾼다.
