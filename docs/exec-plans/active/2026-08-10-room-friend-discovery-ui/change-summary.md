# Change Summary

- 방 내부 채팅·참가자·재생목록의 실제 스크롤 컨테이너에서 스크롤바를 숨기고 키보드 포커스 경로를 유지했다.
- 채팅 하단 정렬, 상단 페이드, hover와 관리 메뉴 레이어·스타일을 정리했다.
- 공통 공개 프로필 본문과 관리 메뉴 셸을 분리하고 FOLLOW 카드에서 중첩 프로필 상세를 열도록 변경했다.
- 공개 프로필 상세에 팔로우/언팔로우와 차단을 연결하고 닫기 및 포커스 복원 경로를 추가했다.
- CREATE·FOLLOW·SETTING 모달 중 데스크톱 탐색 dock의 방 이동 액션만 잠그고 top bar 높이를 안정화했다.
- 방 생성 wizard가 방문한 단계로 재이동하면서 모든 입력값을 보존하도록 변경했다.
- 썸네일 업로드, 방 생성/수정, 프로필 수정 오류에서 사용자에게 HTTP 상태 코드를 노출하지 않도록 정리했다.
