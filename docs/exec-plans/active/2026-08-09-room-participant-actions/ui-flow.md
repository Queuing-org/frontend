# UI Flow

1. 현재 사용자가 방장이면 본인을 제외한 참가자 카드 전체가 클릭 가능한 사각 영역으로 표시된다.
2. 카드를 누르면 해당 카드 아래 관리 액션이 열리고 첫 액션으로 focus가 이동한다.
3. 다른 참가자를 누르면 기존 메뉴를 닫고 새 참가자 메뉴만 연다.
4. 같은 카드를 다시 누르거나 바깥 클릭 또는 Escape 입력 시 메뉴를 닫는다.
5. 회원은 팔로우 관계에 맞는 액션과 신고, 차단, 내보내기, 방장 위임을 본다.
6. 게스트는 계정 slug와 채팅 발신자 식별이 필요한 액션 없이 내보내기만 본다.
7. 신고 가능한 메시지가 없으면 메뉴를 닫고 panel 하단에 안내한다.
8. 방장 위임 성공 시 메뉴를 닫고 안내를 표시하며 새 방장 상태를 다시 조회한다.
