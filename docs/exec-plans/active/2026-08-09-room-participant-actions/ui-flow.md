# UI Flow

1. 현재 사용자가 방장이면 본인을 제외한 관리 가능한 참가자 카드 hover/focus에서 `…` trigger가 표시된다.
2. `…`를 누르면 채팅이 쓰는 공통 dropdown이 카드 위에 떠서 열리고 첫 액션으로 focus가 이동한다.
3. 다른 참가자의 `…`를 누르면 기존 메뉴를 닫고 새 참가자 메뉴만 연다.
4. 같은 `…`를 다시 누르거나 바깥 클릭 또는 Escape 입력 시 메뉴를 닫는다.
5. 회원은 팔로우 관계에 맞는 액션과 신고, 차단, 내보내기, 방장 위임을 본다.
6. 게스트는 계정 slug와 채팅 발신자 식별이 필요한 액션 없이 내보내기만 본다.
7. 신고 가능한 메시지가 없으면 메뉴를 닫고 panel 하단에 안내한다.
8. 방장 위임 성공 시 메뉴를 닫고 안내를 표시하며 새 방장 상태를 다시 조회한다.
9. 하단 공간이 부족한 참가자의 dropdown은 위쪽으로 열린다.
