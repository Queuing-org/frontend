# UI Flow

1. 로그인 사용자는 본인을 제외한 회원 참가자 카드 hover/focus에서 `…` trigger를 본다.
2. 방장은 게스트를 포함해 내보낼 수 있는 다른 참가자 카드에서도 `…` trigger를 본다.
3. `…`를 누르면 채팅이 쓰는 공통 dropdown이 카드 위에 떠서 열리고 첫 액션으로 focus가 이동한다.
4. 일반 로그인 사용자는 다른 회원에게 팔로우/언팔로우, 신고, 차단을 사용한다.
5. 방장은 다른 참가자에게 내보내기를, 다른 회원에게 방장 위임을 추가로 사용한다.
6. 다른 참가자의 `…`를 누르면 기존 메뉴를 닫고 새 참가자 메뉴만 연다.
7. 같은 `…`를 다시 누르거나 바깥 클릭 또는 Escape 입력 시 메뉴를 닫는다.
8. 신고 가능한 메시지가 없으면 메뉴를 닫고 panel 하단에 안내한다.
9. 방장 위임 성공 시 메뉴를 닫고 새 방장 상태를 다시 조회한다.
10. 하단 공간이 부족한 참가자의 dropdown은 위쪽으로 열린다.
