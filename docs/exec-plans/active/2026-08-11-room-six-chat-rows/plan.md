# 방 채팅 6행 최소 가시 높이

## 상태

- ready
- 브랜치: `dev`
- 전달 범위: 기존 사용자 지시를 이어 로컬 커밋까지만 수행한다. push 및 PR 생성·갱신은 하지 않는다.

## 요청

- 24인치 4K부터 가로형 패드와 세로가 짧은 와이드 화면까지, 한 줄 채팅을 가정했을 때 방 중앙 채팅 목록에서 최소 6개 메시지가 보이게 한다.
- 브라우저 zoom이나 전역 transform 없이 실제 viewport 높이에 맞춰 연속적으로 밀도를 조절한다.

## 지원 경계

- 대상: joined room의 desktop/landscape layout, `width > 760px && height >= 600px`
- 모바일 전용 레이아웃 `width <= 760px`은 이번 계산 대상에서 제외한다.
- 대표 viewport:
  - `3840x2160`, `2560x1440`, `1920x1080`
  - `1536x960`, `1536x864`, `1366x768`
  - `1024x768`, `1280x720`, `1024x600`

## 높이 모델

- normal 한 줄 메시지 행: 48px
- 메시지 사이 간격: 16px
- 목록 상하 padding 합: 28px
- 6행 최소 높이: `48*6 + 16*5 + 28 = 396px`
- 높이별 density:
  - `height >= 1100`: `1`
  - `900 <= height < 1100`: `0.8 → 1` 선형 보간
  - `600 <= height < 900`: `0.64 → 0.8` 선형 보간
  - `height < 600`: `0.64` 하한 유지, 6행 보장은 지원 범위 밖
- 채팅 최소 높이와 신청자 카드 높이를 먼저 예약하고 남은 높이로 16:9 플레이어 폭을 계산한다.

## 구현 범위

- `RoomPlaybackScreen`이 방 전용 CSS 변수로 채팅·신청자 카드 density와 플레이어 폭을 소유한다.
- `ChatArea`와 `CurrentRequesterCard`는 방 컨테이너의 CSS 변수를 소비하되 독립 사용 시 기존 크기를 fallback으로 유지한다.
- 중앙 채팅 섹션에 계산된 6행 최소 높이를 적용한다.
- 영상은 16:9를 유지하고 신청자 카드 유무에 따라 남은 높이를 다르게 계산한다.
- 한 줄 채팅 가정은 기존 `white-space: pre-wrap`에서 실제 내용이 줄바꿈되지 않는 입력에 한정한다.

## 수용 조건

- 대표 viewport 모두에서 계산상 채팅 content box가 6행 최소 높이 이상이다.
- 600~1100px 구간에서 채팅 density가 높이에 따라 단조 증가하고, 모든 정수 높이에서 6행 공간을 유지한다.
- 4K와 1440p에서는 기존 최대 크기를 유지한다.
- 16:9 영상 비율, 컨트롤 바 예약 공간, 플로팅 패널 드래그 좌표는 유지한다.
- 방 외부와 모바일 레이아웃에는 새 density가 전파되지 않는다.

## 선택한 기술 경로

- `queuing-feature-delivery`: 로컬 QA·커밋 경계를 관리한다.
- `queuing-orchestrator`: 채팅·영상·신청자 카드의 높이 계약을 하나의 run으로 조정한다.
- `queuing-ui-flow`: 방 중앙 채팅과 고정 컨트롤/플로팅 상태를 보존한다.
- `frontend-architecture-guardrails`: 방 화면이 레이아웃 변수를 소유하고 leaf UI가 소비하도록 책임을 유지한다.
- `queuing-qa-reviewer`: 실제 diff와 대표 viewport 계산을 fresh read-only로 검토한다.

## 잔여 위험

- 실제 브라우저가 연결되지 않으면 pixel-level 시각 확인은 정적 계산과 production build로 대체한다.
- 높이 600px 미만은 영상·신청자 카드·채팅 6행을 동시에 실사용 크기로 보장하지 않는다.
- `900→901px` compact 경계에서는 6행을 유지하지만 신청자가 있을 때 영상 폭이 약 `512→463px`로 줄어드는 시각적 점프가 있다.
- `1024x600`은 6행 우선 결과로 영상 약 `161x90px`, 신청자 설명 8.96px까지 작아진다.
