# 팔로우 목록 요약 UI 정리

## 목표

- 팔로잉·팔로워·차단 목록의 빈 상태 문구와 배치를 통일한다.
- 팔로잉·팔로워 탭에 현재 조회 가능한 인원 수를 표시한다.
- 다운로드한 팔로잉·팔로워 아이콘을 14px 크기로 적용한다.

## 범위

1. 공통 빈 상태 스타일을 `18px`, semibold, `#AAAAAA`로 변경한다.
2. 세 목록의 빈 상태를 탭 패널 가운데에 동일하게 배치한다.
3. 팔로잉·팔로워 첫 페이지 캐시를 재사용해 탭 수를 표시한다.
   - API에 전체 개수 필드가 없으므로 `size=100` 범위의 개수를 사용한다.
   - 다음 페이지가 존재하면 `100+`로 표시해 전체 개수처럼 오인되지 않게 한다.
4. 최신 다운로드 SVG 두 개를 저장소 자산으로 복사하고 탭에 적용한다.
5. 관련 단위 테스트와 전체 lint/test/build를 실행한다.

## 비범위

- 팔로우 API 계약 변경
- 전체 개수를 얻기 위한 추가 페이지 순회
- 사용자가 별도로 수정한 검색 입력창 폭 CSS
