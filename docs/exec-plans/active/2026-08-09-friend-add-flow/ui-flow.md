# UI Flow

```text
FRIEND 패널
  └─ + 친구 추가
       └─ 친구 추가 모달
            ├─ 닉네임 입력
            ├─ 검색 결과: 프로필 이미지 + 닉네임
            ├─ 결과 선택 → 입력값에 닉네임 채움
            ├─ 취소 → 모달 닫기
            └─ 팔로우 → 성공 또는 서버 오류 표시
```

검색 결과는 선택 전까지만 열어 둔다. 선택 후 사용자가 입력값을 다시 수정하면 선택 상태와 mutation 메시지를 초기화하고 새 검색 결과를 표시한다.
