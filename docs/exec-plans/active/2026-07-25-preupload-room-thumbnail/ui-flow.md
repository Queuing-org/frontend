# UI Flow

## State Owner

방 생성 모달이 파일 선택과 임시 업로드 mutation의 조합 상태를 소유한다. 서버에 저장된 임시 업로드 결과는 다른 화면에서 공유하지 않으므로 전역 context나 query cache에 복제하지 않는다.

## Flow

1. 사용자가 기본 정보 단계에서 파일을 선택한다.
2. 클라이언트 확장자/크기 검증에 실패하면 즉시 로컬 오류를 표시한다.
3. 검증 성공 시 로컬 미리보기를 만들고 임시 업로드 mutation을 시작한다.
4. 업로드 중에는 입력과 단계 이동을 잠근다.
5. 실패하면 입력 근처에 서버 오류를 표시하고 기본 정보 단계를 벗어나지 못하게 한다.
6. 성공하면 token을 mutation data로 보관하고 다음 단계를 허용한다.
7. 완료 시 token을 방 생성 payload에 포함한다.

## Recovery

- 파일 재선택: 이전 업로드 오류와 성공 token을 reset하고 새 파일 업로드
- 선택 제거: 로컬 미리보기와 성공 token을 함께 제거
- 방 생성 실패: 성공한 임시 token을 유지해 사용자가 생성 요청만 재시도 가능
