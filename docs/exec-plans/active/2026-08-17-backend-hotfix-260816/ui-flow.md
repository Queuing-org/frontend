# UI Flow

## 참여 중인 방 충돌

- 홈·검색·랜덤·비밀번호·직접 URL에서 동일한 join 전용 다이얼로그를 사용한다.
- 제목/본문은 backend `data.title`의 기존 방을 설명한다.
- `돌아가기`, backdrop, Escape는 모두 `data.slug`로 이동한다.
- 최초 포커스는 `돌아가기`; 확인 처리 중 두 버튼을 잠그고 빨간 spinner를 표시한다.
- 확인 재요청 실패는 빨간 알림을 표시하고 모달을 유지한다.

## 다이얼로그 시각 계약

- 기본 `496×314px`, radius `20px`, padding `40px`.
- 좁은 viewport에서는 크기를 줄이고 내부 스크롤을 허용한다.
- 제목 `24px/600/#242424`, 본문 `20px/400/#242424`.
- 돌아가기 `20px/400/#3C3C3C`.
- 참여하기 `20px/400/#FF0000`, pill radius, hover/focus `rgba(255, 0, 0, 0.06)`.
- `role=dialog`, 제목·설명 연결.
