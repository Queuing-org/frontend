# 방 안전 작업과 썸네일 UI 정리

## 목표

- 큐잉 기본 이미지가 실제 표시될 때만 방 배경과 채팅 hover 색을 분기한다.
- 채팅 관리 버튼을 닉네임 줄 우측 끝에 정렬한다.
- 비밀번호 직접 진입을 기존 비밀번호 모달 UI로 통일한다.
- 방 나가기와 삭제에 확인 절차를 추가하고 삭제 REST 계약과 캐시를 연결한다.
- 생성 썸네일을 업로드와 기본 상태 중 선택할 수 있게 한다.

## 제약

- 테스트 파일은 추가하거나 수정하지 않는다.
- 참가자 및 기존 공용 모달 크기를 변경하지 않는다.
- `dev`에 로컬 커밋만 만들고 push/PR은 하지 않는다.

## 검증

- `git diff --check`
- `npm run lint`
- `npm run build`
- fresh read-only QA
